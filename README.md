### What I learned

En este proyecto aprendí a utilizar listas descriptivas y tablas de forma semántica en HTML. Usé `dl`, `dt` y `dd` para relacionar conceptos con sus respectivos valores, por ejemplo el tipo de tiempo de preparación y su duración. También aprendí que puedo agrupar cada pareja de `dt` y `dd` dentro de un `div` para facilitar su organización y estilo sin perder la semántica.

Además, entendí cómo estructurar tablas con `table`, `tbody`, `tr`, `th` y `td`. Cada fila representa un dato nutricional, donde `th` identifica el nutriente y `td` contiene su valor. El atributo `scope="row"` ayuda a que esta relación sea clara también para tecnologías de asistencia.

Estoy orgulloso de haber intentado construir este proyecto con HTML semántico, no solo buscando que se vea parecido al diseño. Elegir las etiquetas según el significado del contenido hace que la página tenga una estructura más clara, accesible y fácil de mantener.

### Continued development

Quiero seguir aprendiendo sobre diseño responsivo para que mis páginas se adapten correctamente a distintos tamaños de pantalla, desde celulares hasta computadoras. Me interesa practicar el uso de media queries, unidades flexibles y herramientas como Flexbox y Grid para crear interfaces más cómodas y accesibles.

También quiero aprender a diseñar interfaces con React. Me gustaría entender mejor cómo dividir una página en componentes reutilizables, manejar información dinámica y crear aplicaciones más organizadas. Mi objetivo es combinar una buena estructura semántica en HTML con diseños modernos, responsivos e interactivos.
